# Hack Camp 2024: Habit Hatchery
A habit-tracking web application created with two teammates during a 12-hour hackathon. Users can name a fish tank after a habit and add a new animal or plant for each day they complete it, turning habit tracking into a playful and visual experience.

[🐟 Devpost](https://devpost.com/software/habit-hatchery)

## Tech Stack

* HTML
* CSS
* JavaScript
* Figma
